TeluguMitra-AI

AI Powered Study Assistant

TeluguMitra-AI is an AI-based study assistant that helps students understand English study materials in simple Telugu.

Features

- Explains English study content in Telugu.
- Easy-to-understand explanations.
- Student-friendly interface.
- AI-powered learning assistance.

Technologies Used

- Python
- HTML
- CSS
- JavaScript
- Artificial Intelligence

Project Objective

The main objective is to help students understand difficult English topics through simple Telugu explanations.
